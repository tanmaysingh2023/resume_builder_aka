# 📝 Resume Builder Web App

A full-stack web application that allows users to **create**, **customize**, and **download professional resumes** using **React**, **Tailwind CSS**, **Node.js**, **MongoDB**, and **LaTeX**. It supports user authentication, multiple templates, real-time preview, and PDF generation.

## 💡 Features

- 🔐 **JWT-based Authentication** (Sign Up / Log In)
- 🧠 **User-friendly Resume Builder Interface** (React + Tailwind CSS)
- 📄 **Real-time LaTeX PDF Resume Generation**
- 🎨 Multiple templates with **customizable sections**
- 📦 **MongoDB Atlas** and **Local Shell** support for saving user resumes
- 📥 Instant **PDF download** after generation
- 📱 Responsive design for desktop and mobile
- 📊 Resume data is saved securely and retrievable for editing later
